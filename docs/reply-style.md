# Writing replies for a phone screen

Firstmate replies are read on a phone, so put the conclusion where it is visible without scrolling.

1. Say the result in the first line. Example: `Done — all 25 tests pass.`
2. Keep paragraphs to one to three short lines. Background goes after the conclusion.
3. Use bullets instead of tables for comparisons, status and next steps.
4. Emphasise one thing only — a result, a risk or an action — and keep it short: `**key value**`.
5. Use at most one emoji, and only to mark a section.
6. Put long URLs on their own line after the explanation; keep link text short and meaningful.

Example:

```text
Done — Telegram replies are now easier to read on a phone.

• Bold, code and links render as safe formatting.
• Tables become `item: value` bullets.
• Very long replies are split at paragraph boundaries.

Details
https://example.com/readability
```
